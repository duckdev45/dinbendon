# 飲料 Bonus（老闆請喝飲料）

## 結果（驗收）
- 負責人在後台「飲料 Bonus」選飲料店（或自己填）、設截止時間（預設現在 +1 小時）、發佈。
- 收單中時，點餐頁畫面正中間彈出飲料卡片：倒數、選飲料、甜度、冰量、加料（可複選），一人一杯，截止前可換、可取消。
  按 × 收起後右下角留按鈕可再打開；已經點過的人進來不自動彈出。
- 飲料一律 L；有 L 價用 L 價。加料錢算公司的，計入金額。飲料不設金額上限（便當 $150 上限不變）。
- 統計、Excel、複製給店家都帶甜度冰量加料，例：「茶花紅烏龍 微糖 少冰 +燕麥粒 × 2」；金額含加料。
- 便當流程不受影響：點餐頁的「這週的便當」永遠是最新一筆便當菜單。

## 不做
- 不即時去 dinbendon.net 抓菜單（SPA、無公開 API）；菜單由開發時抓進 `src/shops.ts`。
- 不做一人多杯、不做飲料備註欄。

## 資料
- weeks 加欄 `kind`（'' / bento / drink）、`addons`（JSON）。
- orders 加欄 `options`（顯示用字串）、`addonIds`（JSON）。舊資料欄位空白 = 便當、沒選項。
- 改 `Code.gs` 後要貼上並部署新版本；表頭會自動補新欄位。

## 驗證

- Demo 模式瀏覽器走一次：開飲料團 → 點餐頁彈窗 → 點一杯 → 統計 / Excel。
- 真的 Apps Script：API 開飲料團、點一杯、取消。
