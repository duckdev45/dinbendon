# 點心 Bonus（下午茶）

## 結果（驗收）
- 後台多一個「點心」分頁：填開團人、選抖內／揪團、自己填店家名稱、自己一項一項加點心（名稱＋單價）、選填上傳一張照片（菜單或點心）、截止時間預設現在 +1 小時，開團。
- 有照片時，點心卡片的店名旁邊有縮圖、點單畫面有大圖（點了開原圖）。
- 收單中時，點餐頁跳出點心卡片（跟飲料團一樣的廣告 → 點單 → 收據 → 右下角倒數小卡），吉祥物是 Q 版車輪餅。一人一份，截止前可換、可取消。
- 點心沒有甜度冰量、沒有加料、沒有「一律 L」。
- 飲料團和點心團可以同時開；右下角兩張小卡上下疊，不互相蓋住。
- 統計、Excel、複製訂單照飲料團的格式，單位是「份」。
- 沒有任何團時，「要開什麼？」多一張開點心團的卡片。

## 不做
- 不內建點心店清單、不做拉霸。
- 沒點心團時右下角不放車輪餅（右下角留給珍奶）。

## 資料
- weeks.kind 多一個值 `snack`，不加新欄位。host / mode 跟飲料團共用。
- 改 `Code.gs` 後要貼上並部署新版本。

## 驗證
- `pnpm test`：點餐頁只顯示收單中的點心團、複製訂單格式（抖內／揪團）。
- `pnpm build` 通過。
